# Business Requirements Specification – UAVGuard

| ID | Requirement |
|----|-------------|
| BR-1 | Detect a damaged propeller from a short vibration record by comparing it with healthy records only. |
| BR-2 | Identify the fault type (edge cut, crack, surface unbalance) from a record of an unseen recording session. |
| BR-3 | Report the detection rate per fault type and severity index and the false-alarm rate on healthy records. |
| BR-4 | Show how a naive record-level split overstates diagnosis accuracy. |

Out of scope: onboard sensing, flight logs (PX4/ALFA), fault progression, deployment.
